# 부스 안내 영상

`부스안내영상_수정_1920x1080.mp4` — 1920×1080, 30fps, 1분 55초, 반복 재생용 (H.264 + AAC).

## 원본에서 고친 곳

| 시간 | 수정 |
|---|---|
| 1:23~1:29 | 아래가 잘린 '오리온자리' 라벨을 지우고, 1:36 장면의 온전한 라벨 글자를 84% 크기로 별 아래 빈 공간 가운데에 넣음 |
| 1:42~1:49 | '나만의 별 키캡을' → '나만의 키캡을' (원본 글자를 옮겨 가운데 정렬, 그림자 다시 계산) |

나머지 프레임과 소리는 원본 그대로입니다. 1:05 마차부자리(밤 10시)를 포함한 시간대별 별자리는 앱 천문 데이터(`constellation-booth/data/sky-slots.json`)와 일치합니다.

## 스크립트 (`scripts/`)

원본 영상 파일만 있으면 같은 결과를 다시 만들 수 있습니다. Python 3 + `opencv-python-headless` + `numpy`, `ffmpeg` 필요.

- `patch.py` — 수정 본체. 장면마다 위치(패널 떠다님·글자 미끄러짐)와 불투명도(페이드)를 프레임별로 추적해 합성합니다.
  `python3 patch.py 원본.mp4 결과.mp4` (미리보기: `--preview 88.0,105.0` → 해당 시각 PNG)
- `analyze.py` — 템플릿 추적으로 장면의 움직임·페이드 구간을 확인하는 도구.
- `fitshadow.py` — 키캡 문구 그림자 모양(σ≈20 흐림 × 1.77) 측정용. 기준 프레임 PNG 경로가 코드에 들어 있습니다.
