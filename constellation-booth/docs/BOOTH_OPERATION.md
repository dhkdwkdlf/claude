# 부스 운영 안내 (운영자용)

행사일 **2026년 11월 4일 수요일**, 관측 기준 **경상북도 봉화군**, 한국 시간.

## 행사 전 체크리스트

- [ ] 두 앱 설치 — 단일 파일(`별자리운세.html`, `별자리여행.html`)을 태블릿에 복사해 Chrome 으로 열거나, 홈 화면 앱으로 설치 (`docs/OFFLINE_SETUP.md`). 운영자 화면에 '오프라인 준비 완료' 표시 확인
- [ ] 비행기 모드에서 종료 → 재실행 → 전체 체험 1회
- [ ] 태블릿 **세로** 거치, 거치대에서 화면 하단(복귀 버튼)이 가려지지 않는지
- [ ] 자동 잠금 끄기 (또는 운영자 화면 '화면 켜짐 유지 요청'이 켜짐으로 표시되는지)
- [ ] 밝기 최대 근처, 글자 크기 기본값(시스템 글자 확대는 끄는 편이 안전)
- [ ] 한국어 키보드 설치·전환 확인 (앱 2 퀴즈)
- [ ] 운영자 화면 '전체화면 요청' (지원 기기) — 거부되어도 사용에는 문제 없음
- [ ] 두 태블릿 이상이면 앱 버전이 같은지
- [ ] 충전 케이블·보조 배터리

## 앱 1 — 별빛이 전하는 오늘의 한마디 (즉석 별자리 운세)

참가자 흐름: **옆으로 밀어 별자리 찾기 → 가운데 카드 한 번 터치(설명) → 한 번 더 터치(뒤집어 운세) → 옆으로 밀어 처음으로**

- 운세 결과는 **자동으로 닫히지 않습니다.** 참가자가 옆으로 밀거나 작은 '처음으로' 버튼을 누르면 카드가 한 바퀴 돌며 처음 화면으로 돌아갑니다. 돌아온 뒤에도 방금 고른 별자리가 가운데 남습니다.
- 운세는 별자리마다 13개 문안을 섞은 덱에서 차례로 나옵니다. 같은 별자리를 13번 열기 전에는 같은 문안이 반복되지 않습니다. 날짜는 기기 날짜와 상관없이 항상 11월 4일 기준입니다.
- 생년월일을 입력받지 않습니다. 참가자가 자기 생일 구간의 카드를 찾도록 안내만 합니다.
- 운영자 멘트 예시: "내 생일이 들어 있는 카드를 가운데로 가져온 다음, 두 번 눌러 보세요."

## 앱 2 — 11월 4일의 별자리 여행 (별자리 찾기 + 한 문제 퀴즈)

참가자 흐름: **별자리 알아보기 → 시간(저녁 6시·밤 8시·밤 10시·다음 날 0시) 바꿔 보기 → 별자리 눌러 설명 보기(여러 개 가능) → 별자리 한 문제 도전 → 정답 → 오른쪽 아래 '처음으로 돌아가기'**

- 퀴즈는 **설명을 본 별자리 중에서만** 한 문제 나옵니다. 아무것도 안 봤으면 "별자리를 먼저 하나 알아보세요." 안내 후 학습 화면으로 갑니다.
- 처음에는 반짝이는 별만 보입니다. 틀리면 '힌트 보기' 버튼이 나타나고, 한 번 누르면 별을 잇는 선, 두 번 누르면 모양이 나타납니다. 세 번째 힌트는 없습니다. 정답을 알려주지 않으니 어려워하면 운영자가 "자리 빼고 이름만 써도 돼요" 또는 첫 글자를 살짝 알려 주세요.
- 정답은 짧은 이름도 됩니다: 페가수스 / 안드로메다 / 카시오페이아 / 세페우스(케페우스) / 페르세우스 / 백조 / 거문고 / 독수리 / 황소 / 오리온 / 양 / 마차부.
- 정답 화면도 **자동으로 닫히지 않습니다.** 다음 참가자를 위해 오른쪽 아래 큰 버튼을 누르도록 안내합니다. 누르면 이전 참가자의 답·힌트·학습 기록이 모두 지워집니다.
- 별자리 그림은 맑고 어두운 하늘을 가정한 계산 결과입니다. 실제 날씨·산·건물·빛 공해는 반영하지 않습니다.
- 저녁 6시는 아직 박명(해가 진 직후, 하늘이 완전히 어둡지 않음)이라 "밝은 별부터 보여요"라고 표시됩니다. 밤 8시 이후가 완전한 밤하늘입니다.

## 운영자 화면

- 여는 법: 첫 화면의 작은 날짜 글자를 2.5초 안에 5번 두드리기, 또는 주소 끝에 `#operator`.
- 할 수 있는 것: 오프라인 준비 상태·앱 버전 확인, 업데이트 확인·적용, 전체화면·화면 켜짐 유지, 저사양 효과 모드, 참가자 화면 초기화, (앱 1) 운세 덱 초기화·진행 보기, (앱 2) 기본 시간·행사 설정 보기.
- 앱 2 에서 행사 날짜·위치를 바꾸면 "데이터 재생성 필요" 경고가 뜹니다. 별 위치 데이터는 봉화 2026-11-04 기준으로 미리 계산된 것이라, 다른 날짜·장소에는 **재생성 없이 쓰면 안 됩니다** (`README.md` 의 데이터 재생성 절차). 실수로 바꿨다면 '설정 되돌리기'.
- 설정 저장이 실패해도 참가자 화면은 계속 동작합니다. 운영자 화면 '저장소' 항목에 경고가 보이면 저장공간을 확인하세요.

## 행사 중 자주 묻는 상황

| 상황 | 대응 |
|---|---|
| 카드를 눌렀는데 운세가 안 나와요 | 한 번 더 누르면 됩니다(두 번 터치). 손가락이 움직이면 '밀기'로 인식되니 가만히 톡 누르기 |
| 운세 화면에서 안 넘어가요 | 옆으로 밀거나 아래 '처음으로' 버튼 |
| 퀴즈에서 Enter 를 눌러도 반응이 없어요 | 한글 조합이 끝나기 전의 Enter 는 무시됩니다. 한 번 더 Enter 또는 '정답 확인' 버튼 |
| 퀴즈 화면에서 다른 별자리로 바꾸고 싶어요 | 문제는 바뀌지 않습니다. '처음으로' → 별자리 알아보기부터 다시 |
| 화면이 멈춘 것 같아요 | 운영자 화면 → '참가자 화면 초기화'. 그래도 안 되면 앱 종료 후 홈 아이콘으로 재실행(오프라인에서도 됩니다) |
| 글자가 작아요/커요 | 태블릿 설정의 글자 크기는 기본값 권장. 앱은 본문 18px 이상·버튼 56px 이상으로 설계 |

## 부록 — '모양 씌우기' 선화 생성 프롬프트

`scripts/shape-refs/<id>-stars.png` 를 첨부하고 아래 문구의 `[SUBJECT]` 만 바꿔 생성합니다. 결과는 `<id>.png` 로 저장해 `python3 scripts/import-shape-art.py <폴더>` 로 반영합니다.

```
Using the attached image as the exact canvas and layout, draw [SUBJECT] as a refined, elegant single-weight line-art figure so that the figure's body naturally fits over the star pattern and connecting lines shown (treat the dots as the figure's key joints; do not move, redraw or add stars). Keep the same 1024x1024 square canvas and composition; the figure should fill roughly the same area as the star pattern. Thin, even, hand-inked ivory (#F7FAFF) lines only, no fills, no shading, no gradients, no gold stars, no text, no labels, no frame. Solid flat deep-navy background (#142543). Calm, classical star-atlas illustration mood, like an antique celestial chart redrawn in a minimal modern line style. Do not draw the star dots or the connecting lines themselves; draw only the figure.
```

[SUBJECT] 예: pegasus = the winged horse Pegasus seen upside-down as on the sky: the large square is its body, the neck and head extend from the lower-right corner toward the far right, two front legs extend from the upper corner, wings sweep from the left side.
