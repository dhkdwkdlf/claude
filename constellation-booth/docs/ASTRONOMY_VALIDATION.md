## 미검증 항목

- Stellarium 등 GUI 천문 프로그램과의 화면 대조는 이 환경에서 수행하지 못했다. 아래 절차로 사용자가 확인할 수 있다.
  1. Stellarium 을 열고 위치를 위도 36.9°N, 경도 128.73°E, 고도 0 m 로 설정한다 (F6).
  2. 날짜·시각을 2026-11-04 20:00 (UTC+9) 로 맞춘다 (F5). '다음 날 0시'는 2026-11-05 00:00.
  3. 대기 굴절을 끄거나(F4 → 조망 → 대기 끄기) 고도 15° 이상 별만 비교한다.
  4. 별을 클릭해 표시되는 방위각/고도(Az/Alt) 를 위 표와 비교한다. 1° 이내면 통과.
- 실제 행사장 좌표가 확정되면 `data/event-config.json` 을 수정하고 `python3 scripts/generate-sky-data.py && python3 scripts/verify-sky-data.py` 를 다시 실행한다.
