# 오프라인 설치 안내 (운영자용)

행사장에서는 Wi-Fi 와 모바일 데이터가 모두 꺼져 있어도 두 앱이 실행·반복되어야 합니다. 그러려면 **행사 전에 인터넷이 되는 곳에서 한 번 설치**해야 합니다. 인터넷을 끈 채 처음 접속하면 아무것도 내려받을 수 없습니다.

## 0. 준비물

- 세로로 거치할 태블릿 (Android: Chrome, iPad: Safari)
- 두 앱이 올라간 **HTTPS 주소** (예: `https://example.com/fortune/`, `https://example.com/sky/`)
  - 주소가 아직 없다면 아래 "A. 빌드를 서버에 올리기"를 먼저 진행합니다.
  - 파일을 더블클릭해 `file://` 로 여는 방식은 오프라인 설치(서비스 워커)가 동작하지 않습니다.

## A. 빌드를 서버에 올리기 (개발자·IT 담당)

1. `release/fortune.zip`, `release/sky.zip` 을 받습니다. (또는 `npm run build && npm run package` 로 생성)
2. 압축을 풀면 `fortune/`, `sky/` 폴더가 나옵니다. 각 폴더를 웹 서버의 **같은 이름의 경로**에 그대로 올립니다.
   - `https://서버/fortune/` ← `fortune/` 폴더 내용
   - `https://서버/sky/` ← `sky/` 폴더 내용
   - 경로를 바꾸려면 `apps/*/vite.config.ts` 의 `base` 와 `manifest.webmanifest` 의 `start_url`·`scope`·`id` 를 함께 바꾼 뒤 다시 빌드합니다.
3. 서버 설정 권장값
   - `index.html`, `sw.js`: `Cache-Control: no-cache`
   - `assets/*`: 장기 캐시 가능 (파일명에 해시 포함)
   - `*.webmanifest` → `application/manifest+json`, `*.woff2` → `font/woff2`, `*.webp` → `image/webp`
4. 간단 검수용: 저장소에서 `npm run preview` 를 실행하면 `http://localhost:4173/fortune/`, `/sky/` 로 열 수 있습니다. `localhost` 는 보안 컨텍스트로 취급되어 서비스 워커가 동작합니다. 태블릿에서 같은 네트워크의 PC 로 접속할 때는 HTTPS 가 아니면 설치가 되지 않으니, 실제 설치는 HTTPS 서버에서 합니다.

## B. 태블릿에 설치하기 (행사 전, 인터넷 연결 상태)

각 앱에 대해 **따로** 진행합니다. 앱 선택 허브는 없고, 홈 화면 아이콘 2개가 생깁니다.

### Android (Chrome)

1. Chrome 으로 `https://서버/fortune/` 접속 → 화면이 뜨면 10초 정도 기다립니다(전체 자산 저장).
2. 메뉴(⋮) → **홈 화면에 추가** 또는 **앱 설치** → 설치.
3. `https://서버/sky/` 도 같은 방법으로 설치합니다.
4. 홈 화면에서 각 아이콘을 열어 **운영자 화면**으로 '오프라인 준비 완료'를 확인합니다 (아래 C).

### iPad (Safari, iPadOS)

1. Safari 로 `https://서버/fortune/` 접속 → 10초 정도 기다립니다.
2. 공유(⬆) → **홈 화면에 추가** → 추가.
3. `https://서버/sky/` 도 같은 방법으로 설치합니다.
4. 홈 화면 아이콘으로 열어 '오프라인 준비 완료'를 확인합니다.
5. iPadOS 는 일정 기간(수 주) 사용하지 않은 웹 앱 저장소를 지울 수 있습니다. **행사 전날·당일 아침에 다시 한 번 열어 준비 상태를 확인**하세요.

## C. 운영자 화면에서 준비 상태 확인

운영자 화면은 참가자에게 보이지 않습니다. 여는 방법 두 가지:

- 첫 화면의 작은 날짜 글자(`2026. 11. 4. 수요일` / `2026. 11. 4. · 봉화 기준 · 한국 시간`)를 **2.5초 안에 5번** 두드립니다.
- 또는 주소 끝에 `#operator` 를 붙여 엽니다. (예: `https://서버/sky/#operator`)

확인할 것:

- **오프라인 준비: 완료** 와 `저장됨 24/24` 처럼 전체 파일 수가 모두 저장되었다는 표시
- 앱 버전 (두 태블릿 이상이면 같은 버전인지)
- '누락 파일' 이 있으면 인터넷이 켜진 상태에서 **다시 확인** → 여전히 누락이면 페이지 새로고침 후 다시 확인

'준비 완료' 가 아닌 상태로 행사장에 가져가지 않습니다.

## D. 비행기 모드 시험 (필수)

1. 태블릿을 **비행기 모드**로 바꾸고 Wi-Fi 도 끕니다.
2. 두 앱을 완전히 종료(최근 앱에서 밀어 닫기)한 뒤 홈 화면 아이콘으로 다시 엽니다.
3. 앱 1: 카드를 양쪽으로 12장 넘기고, 가운데 카드 두 번 터치 → 운세 → 슬라이드 복귀까지.
4. 앱 2: 시간 4개 전환 → 별자리 설명 2개 이상 → 퀴즈 → 오답 → 힌트 2단계 → 정답 → 처음으로.
5. 각 앱에서 화면을 아래로 당기거나(새로고침) 운영자 화면의 '다시 확인'을 눌러 준비 완료가 유지되는지 봅니다.
6. 태블릿을 **재부팅**한 뒤 2~4 를 한 번 더 합니다.

## E. 업데이트

- 새 빌드가 서버에 올라가면 앱은 **자동으로 바꾸지 않습니다.** 인터넷이 켜진 상태에서 운영자 화면 → '업데이트 확인' → 새 버전이 대기 중이면 **체험이 끝난 뒤** '업데이트 적용(새로고침)'을 누릅니다.
- 앱 1 을 업데이트해도 앱 2 의 캐시는 건드리지 않습니다(캐시 이름이 앱별로 분리).

## F. 문제가 생겼을 때

| 증상 | 조치 |
|---|---|
| 오프라인에서 열면 "사이트에 연결할 수 없음" | 설치가 완료되기 전에 인터넷을 껐거나 저장소가 지워진 경우. 인터넷을 켜고 앱을 열어 10초 대기 → 운영자 화면에서 준비 완료 확인 → 다시 비행기 모드 |
| 브라우저 '저장공간 정리' 후 앱이 비어 있음 | 위와 같이 재설치. 저장소가 절대 지워지지 않는다고 보장할 수 없으므로 **행사 당일 아침 재확인** |
| 준비 상태가 '미완료'에서 바뀌지 않음 | 주소가 HTTPS 인지 확인. 서버에 `sw.js`, `precache-manifest.json` 이 올라갔는지 확인. 다른 브라우저 탭을 모두 닫고 새로고침 |
| 화면이 자동으로 꺼짐 | 운영자 화면 '화면 켜짐 유지 요청'. 미지원 기기는 설정 → 디스플레이 → 자동 잠금 '안 함' |
| 한글 키보드가 안 뜸(앱 2 퀴즈) | 기기 설정에서 한국어 키보드 추가. 입력창을 눌러 키보드가 뜨는지 확인 |

## G. 검증된 환경과 미검증 환경

- 검증: Chromium(Playwright) 자동 검수에서 설치 → 전체 사전 캐시 → 오프라인 재실행·새로고침·미방문 화면·앱 1 캐시 삭제 후 앱 2 실행 통과 (`docs/TEST_REPORT.md`).
- **미검증**: 실제 Android 태블릿 Chrome, iPad Safari 의 설치·보존·재부팅 동작. 위 D 절차로 실제 행사 기기에서 확인한 뒤 `docs/TEST_REPORT.md` 의 미검증 항목에 결과를 적어 주세요.
